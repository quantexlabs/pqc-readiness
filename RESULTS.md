# Provisional fixture results

Only the deterministic fixture artifacts listed below are regenerated by
`python scripts/regenerate_results.py`. The specification is retrospective and labels
are repository-authored; independent authorship/adjudication are unverified.
Independent-validation stop rule remains unmet; no held-out corpus or competitor was run.

## Regeneration

```bash
python scripts/regenerate_results.py
python scripts/regenerate_results.py --check
```

Outputs: results/evaluation/{results.json,primary.json,metrics.svg} and
results/latest/{findings.json,inventory.cbom.json,migration_plan.json,report.html,evaluation.json}.
The fixture pipeline contains four local classes and skips TLS. CI checks normalized
artifact equality; only generated CBOM UUIDs and timestamps are ignored, including HTML excerpts.
No timing is mixed into deterministic metrics. math.fsum supplies stable bootstrap means
on the tested Python 3.11 and 3.12 runtimes. Regeneration also refreshes data/CHECKSUMS.json;
--check rejects both stale normalized artifacts and mismatched raw-byte integrity hashes.

## Separate resource receipts

`python scripts/measure_resources.py` records three whole-command wall-time/peak-RSS runs
per command using os.wait4, including interpreter startup. Sanitized environment and
measurements are retained in docs/evidence/r3/resources.json. These are tiny local runs,
not a hardware guarantee, scale benchmark, or a measured validation of policy assumptions.
Those historical receipts used the earlier local environment. The R4 clean-checkout
matrix uses requirements-dev.txt; Python 3.12 dependencies were installed from the local
package cache. Fresh network acquisition was unavailable.

## Limits

Comments, strings, aliases, negative examples and unparsed AES key sizes have separate
regressions in data/evaluation/regression_cases.json. The known alias miss is visible.
These cases are not independent adjudication or held-out data. Metrics do not score
parameters, operational status, policy accuracy or production completeness. TLS is mocked
separately; no live-success claim is made. CBOM syntax validation uses the documented
pinned derivative and official-source syntax receipts. Domain review and consumer
ingestion remain unverified.
No strength/category mapping is emitted. See README for limits and heuristic rationale.

[Figure](results/evaluation/metrics.svg) includes values, F1 intervals and fixture support.
Prior-art capability references are pinned to immutable README revisions in
[docs/PRIOR_ART.md](docs/PRIOR_ART.md); no competitor was executed.
